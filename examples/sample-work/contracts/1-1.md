## 契約内容

- **role**: 第1話の hook。少女が「まだ忘れていない物は預かれない」規則に触れる。
- **situation**: 放課後、雨。駅の西口に昨日できた忘れ物預かり所。
- **pov**: 三人称限定 (ミナ)。
- **participants**: ent-c01 (ミナ), ent-c02 (係員)
- **required_events**: ミナが傘を返してもらおうとする / 係員が拒む / ミナが屋上に傘を置く
- **forbidden**: 世界の規則を講義する / 係員を悪役にする
- **agency**: ミナが「わざと忘れる」と決める
- **state_changes**: 傘がミナの手元から離れる
- **end_state**: ミナが傘を置き、明日取りに来ると決める
- **connections**: → 1-2 で傘を受け取る
- **style**: `craft/voice.md`。短い文。感情語を使わない。

## craft 欄 (面白さの設計)

- **scene_job** — 少女が、規則に従って「忘れる」ことを自分で選ぶ場面
- **dramatic_question** — ミナは傘を預けられるのか
- **want** — ミナが自分の傘を今すぐ取り戻したい
- **obstacle** — 係員が「まだ忘れていない」と受け取りを拒む
- **turn** — 取り戻すと思ったら、忘れてから来いと言われる
- **cost** — 傘を持ったまま雨へ戻り、わざと置き忘れる
- **entry** — 「お預かりは、まだです」
- **exit** — 傘を持たずに帰るのは、生まれてはじめてだった。
- **button** — 手のひらに、持ち手の形が残っていた。
- **detonator** — 係員が「あなたが、いちばん最後に忘れる予定の物です」と言う
- **concrete_details** — 名札のついた紺の布傘 / 名簿の罫線 / 窓口の小さな鈴
- **subtext** — 表面「忘れたら、預かってもらえるんですか」/ 本音「返してほしい」
- **skip_test** — 飛ばすと、傘が「わざと忘れられた物」である意味が分からなくなる
- **pov_filter** — 係員の内心は書かない。ミナの知覚と動作のみ
- **voice_notes** — 短い文。台詞は1行1目的。感情語を使わない
- **prose_floor** — 600
- **prohibit_summary** — true
