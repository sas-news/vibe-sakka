## 契約内容

- **role**: 第1話の payoff と pull。返ってきた傘に、忘れた記憶の痕跡がある。
- **situation**: 翌日の放課後。雨は止んでいる。
- **pov**: 三人称限定 (ミナ)。
- **participants**: ent-c01 (ミナ), ent-c02 (係員)
- **required_events**: 傘を受け取る / 持ち手の文字を見つける / 誰にもらったか思い出せない
- **forbidden**: 「ミナへ」の書き手を説明する / 記憶を名前で説明する
- **agency**: ミナが「明日は何を忘れよう」と自分で決める
- **state_changes**: 傘が戻る。ミナは贈り主を思い出せなくなる
- **end_state**: ミナが、忘れることを選び続けると決める
- **connections**: 1-1 の「忘れる」選択の代償が返ってくる
- **style**: `craft/voice.md`。

## craft 欄 (面白さの設計)

- **scene_job** — 忘れた代償が返ってくる場面。喪失を静かに受け取る
- **dramatic_question** — 返ってきた傘に、何が残っているのか
- **want** — ミナが傘を受け取り、何を忘れたのか知りたい
- **obstacle** — 係員は「忘れた人にも分かりません」と答えない
- **turn** — 持ち手に他人の感謝と、自分の名前が書いてある
- **cost** — 傘を誰にもらったか、思い出せなくなる
- **entry** — 「お預かりの、傘ですか」
- **exit** — 誰に、もらったかは、思い出せなかった。
- **button** — 明日は、何を忘れよう。彼女は、そう思った。
- **detonator** — 持ち手の内側に『ミナへ』と書いてある。書いた覚えはない
- **concrete_details** — 消しかけの鉛筆の文字 / 名札の外された跡 / 指先の鉛筆の粉
- **subtext** — 表面「私は、何を忘れたんですか」/ 本音「思い出したい」
- **skip_test** — 飛ばすと、傘が贈り物だったことと、代償の意味が分からなくなる
- **pov_filter** — 係員の内心は書かない
- **voice_notes** — 短い文。説明しない。余白を残す
- **prose_floor** — 600
- **prohibit_summary** — true
