# export — 原稿の書き出し

`scenes/` に散った本文を読める原稿にまとめる。

## 手順

1. `plan/tree.md` で話・シーンの公開順を確定する。
2. status: generated のシーンを順に読み、本文部分だけを連結する
   (シーンファイルのヘッダ・メタ情報は原稿に入れない)。
3. 話の境には `plan/tree.md` の話タイトルを見出し (`# 第N話 …`) として
   入れる。シーン間は空行または区切り (作品のトーンに合わせる)。
4. 未生成のシーンは `[※未執筆]` プレースホルダを入れるか、指定が
   あれば出力から除外する。両方の場合も出力のどこが欠けているか
   一覧を報告する。
5. `out/<作品タイトル>.md` (タイトル未定なら `out/manuscript.md`) に
   書き出し、シーン数・文字数・欠けているシーンを報告する。

## 注意

- 本文は一字一句変えない (export は結合のみ。直したい箇所は
  `.agents/skills/change-set` 経由)。
- `out/` は生成物置き場。正典・計画・契約の状態には一切触れない。
