# export — 原稿の書き出し

`scenes/` に散った本文を読める形にまとめる。**結合のみ — 本文は
一字一句変えない** (直したい箇所は `.agents/skills/change-set` 経由)。

## 手順

1. `plan/tree.md` で話・シーンの公開順を確定する (tree は公開順一列に
   正規化されている前提)。
2. status: generated のシーンを順に読み、本文部分だけを連結する
   (シーンファイルのヘッダ・メタ情報は原稿に入れない)。
3. 話の境には `plan/tree.md` の話タイトルを見出しとして入れる。
   シーン間は空行または区切り (作品のトーンに合わせる)。
4. 未生成のシーンは `[※未執筆]` プレースホルダを入れるか、指定が
   あれば出力から除外する。どこが欠けているか一覧を報告する。
5. シーン数・文字数・欠けているシーンを報告する。

## 出力形式

- **`out/<作品タイトル>.md`** (標準。タイトル未定なら `out/manuscript.md`)
- **`out/<作品タイトル>.txt`** (投稿用プレーンテキスト): markdown 記号を
  落とし、章見出しは `第N話 タイトル` のプレーン行にする。
  投稿サイトへの貼り付け用
- **`out/episodes/<NN>-<話タイトル>.md`**: 話ごとの分割出力。
  連載・話単位の投稿向け。指定があれば
- **`out/<作品タイトル>.epub`**: pandoc 等の変換ツールが使える環境なら
  任意で生成する。ツールがなければ md/txt を出すだけで十分 — export
  自体は変換ツールに依存しない

## auto 運転中の扱い

export は無害な生成物なので承認不要。`autonomy` の品質停車点で
beta-read へ渡す原稿を出す、作者の「読みたい」に随時応える、の用途で
自律的に走らせてよい。

## 注意

- `out/` は生成物置き場。正典・計画・契約の状態には一切触れない。
- 同じファイル名への上書きでよいが、重要な版を残す場合は
  `out/<title>-r<rev>.md` のように版を分ける。
