# 興味スコアカード (採点用紙)

> 外部読者 (正典・計画を知らない新規コンテキスト) が原稿を読み、10観点を
> 0–4で採点する用紙。**同一コンテキストの自己採点はテストとして無効。**
> 合否は high 1件以上 or medium 3件以上 → 不合格 (revise 最大2回)。
> 採点基準の詳細は `docs/CRAFT.md` §10。
>
> **記録先**: `reviews/beta-<対象>-<date>.md` の「興味スコアカード」節に
> この表を貼る (`templates/beta-review.md`)。`reviews/interest-*.md` は
> 作らない — 通読レビューと採点は1ファイルにまとめる。

```yaml
target: "第1話"                    # 対象 (話・範囲)
date: 2026-11-17
reader: external                 # external=新規コンテキスト / self=自己採点 (無効)
context: subagent               # subagent | external_llm | session | self
manuscript: out/sample.md        # 読者が読んだ原稿のパス
scenes_reviewed: 2
```

## 採点 (0=最悪 4=最良)

各観点に「本文からの引用」を1つ添える。引用できない観点は0点とする。
迷ったら低い方につける。

| # | 観点 | 0 | 2 | 4 | 点 | 引用・根拠 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 冒頭フック | 説明から始まる | 異物はあるが弱い | 3行以内に問いが立つ | | |
| 2 | 章末の引き | まとめで終わる | 予想内の出来事 | 未解決の問い+具体 | | |
| 3 | 意外性 (detonator) | ない | 1回あるが納得が弱い | 裏切り+読み返すと伏線 | | |
| 4 | 感情の動き | 名指しのみ | 1回動く | 2回動き、最後に残る | | |
| 5 | 具体物の記憶 | 抽象語だけ | 1つ挙げられる | 3つ以上、軸になる物がある | | |
| 6 | 台詞の生々しさ | 説明口調 | 情報を運ぶ | 言わないことが伝わる | | |
| 7 | テンポ | 飛ばした箇所が複数 | 1箇所 | 飛ばした箇所がない | | |
| 8 | 人物の欲求 | 言えない | 言えるが弱い | 1文で言え、障害と衝突する | | |
| 9 | 世界の知覚 | 五感がない | 視覚のみ | 二感以上ある | | |
| 10 | 続きを読みたいか | 読まない | 気が向けば | 今すぐ次を読む | | |

採点者の記入例: `1 | 冒頭フック | … | 3 | 「忘れ物預かり所は、駅の西口に、
昨日からあった。」`

## severity 換算と合否

- 0–1点 = high / 2点 = medium / 3–4点 = 問題なし。
- **high 1件以上、または medium 3件以上で不合格。** 平均点は見ない。
- 合格 = high 0 かつ medium 2以下 (目安)。`work.md` で閾値を変更できるが、
  変更した場合は `work.md` に理由を書く。

記入例:
```text
high: 1件 (具体物の記憶=0) / medium: 2件 → 不合格。§6で具体物を3つ入れて revise。
```

## 自由記述 (読者の言葉のまま)

- **どこで読むのをやめたか** (引用+理由):
- **次を読む理由は何か** (1文):
- **一番記憶に残った具体物は何か**:
- **予想を裏切られた箇所はどこか**:
- **感情が動いた箇所はどこか**:
- **退屈した箇所はどこか** (引用):

記入例: 「どこでやめたか: L38『係員は規則の説明を続けた』— 説明が続いた。」

## 判定

- interest gate: 不合格 / 合格
- 次の行動: `revise` (最大2回) / `polish` に回す / 作者に報告
- 記録: `reviews/beta-<対象>-<date>.md` に貼り、`plan/tree.md` の該当話に
  `interest: pass|fail` を記す。

記入例: 「不合格 → write-scene で revise 1回目 (具体物3つ追加) → 再採点で合格。」
